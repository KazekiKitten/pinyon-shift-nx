# Pinyon Shift 0.5.1

Fixes for setup, the title update v4 build, the Android build, laptops with
two GPUs and tearing with VSYNC on, plus faster recompiled code.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. 0.5.0 launchers offer this update from
**Update to 0.5.1**.

## Fixed

- **Tearing with VSYNC on** (Vulkan, the default renderer): the game used a
  present mode that tears whatever VSYNC said. With VSYNC on it no longer
  tears, and turning VSYNC on or off applies at once (#539).
- **Laptops started the game on the integrated GPU**; NVIDIA Optimus and
  AMD switchable graphics now pick the high-performance one (#534). The
  troubleshooting page says how to choose a GPU by hand.
- **Setup**
  - The Visual Studio Build Tools installer no longer starts once per
    option in a loop, and a failed repair reports the installer's own
    error and logs (#458, #533, #498, #502).
  - A system without the `ComSpec` environment variable no longer stops
    setup at once (#541).
  - A disc image that isn't the reference dump is checked file by file
    again instead of stopping with an error (#462).
  - macOS counts the space it frees on demand, as Finder does (#461).
  - Linux distributions with libxml2 2.14 or newer (SteamOS, Arch and
    others) can build again (#472, #474, #514).
- **Title update v4 build**: a release install found neither the SDK nor
  the translated v4 code, so the first v4 build always failed (#459, #540).
- **Android build** on Windows failed with "The command line is too long"
  when the user folder's path was long or had a space (#538).
- **Android HDR** on the AYN Odin 2 Portal was blown out or washed out; it
  is now HDR10 with metadata matching the display (#500).

## Faster

- **Native replacements for hot game functions**, checked against the
  game's code before use: the math library's `pow` and the asset
  decompressor run about 2.2 times faster, mostly shortening loading, and
  the render thread sleeps instead of spinning while it waits for a new
  frame (desktop race mean frame 9.77 to 9.42 ms, p99 18.5 to 16.9 ms on an
  RTX 4080).
- **Leaner recompiled code**, measured as instructions a second on the
  Odin's race: condition flags kept in locals cut 7 to 9 % on the
  simulation, render and audio threads, and direct stack accesses another
  17 to 18 % on the simulation and render threads. The desktop executable
  shrinks from 97.7 to 88.4 MB.
- On Android, Linux and macOS, waits wake on a signal instead of polling
  every millisecond (6 to 9 % less CPU on the Odin).
- On Adreno 8xx Android devices the app now picks the bundled Turnip gen8
  v37 driver, as on Adreno 7xx: about a fifth less GPU time per race frame
  than the system driver on the Adreno 830 (20.2 against 24.8 ms).

## Diagnostics

- Settings changes are written to the session log, so a crash report shows
  what was changed just before (#542).

## Known limitations

- DLC import and the title update build are Windows only (Android gets them
  from the PC); Linux and macOS don't have them yet.
- AMD and Intel GPUs on PCs are not qualified yet; the Steam Deck is.
  Racing wheels aren't supported (#337).
- The immersive camera isn't available on Android or the v4 build.
